# 🌐 Matvey Chromium

Моя версия **ungoogled-chromium** для Linux с готовыми настройками!

## ✨ Что внутри

- 🎨 **Тёмная тема** — приятно для глаз
- 🚫 **Блокировка рекламы** — uBlock Origin
- 🌙 **Dark Reader** — тёмная тема на ВСЕХ сайтах
- 📺 **Enhancer for YouTube** — удобные кнопки + блокировка рекламы на YouTube
- 🔧 **JSON Viewer** — красиво показывает конфиги

## 📥 Установка

### 1. Скачай ungoogled-chromium

```bash
# Ubuntu/Debian
sudo add-apt-repository ppa:ungoogled-chromium/stable
sudo apt update
sudo apt install ungoogled-chromium

# Arch Linux
yay -S ungoogled-chromium

# Fedora
sudo dnf install ungoogled-chromium
```

### 2. Запусти скрипт установки

```bash
git clone https://github.com/vityazevmatvey/matvey-chromium.git
cd matvey-chromium
chmod +x install.sh
./install.sh
```

### 3. Готово! 🎉

Запусти браузер — все расширения уже настроены!

## 🔧 Что делает скрипт

- Создаёт папку профиля с настройками
- Устанавливает расширения
- Включает тёмную тему
- Настраивает блокировку рекламы

## 🎮 Для стримеров

Этот браузер отлично подходит для стримов:
- Нет рекламы на YouTube
- Тёмная тема везде
- Быстрая загрузка страниц
